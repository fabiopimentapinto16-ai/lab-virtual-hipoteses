# Assets 3D: origem e licença

Nenhum modelo 3D externo é usado. Pâncreas, fígado, célula e grafo de via são **gerados em código** (`src/ui/organ3d.ts`, geometrias primitivas do three.js: esferas, tubo, cone, icosaedros), autoria deste projeto, licença MIT.

| Asset | Origem | Licença |
|---|---|---|
| Pâncreas (cabeça, corpo, cauda, ilhotas) | procedural (Three.js) | MIT |
| Fígado (lobos direito/esquerdo) | procedural (Three.js) | MIT |
| Célula e via molecular | procedural (Three.js) | MIT |

Biblioteca: [three.js](https://threejs.org) (MIT). Se no futuro entrarem arquivos GLB, listar aqui autor, URL e licença antes de commitar.
